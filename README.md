# My Budget Tracker

## Project Description

My Budget Tracker is a simple web application for tracking personal income and expenses. This Week 2 version builds on the static structure from Week 1 by adding an expense table, an improved expense form, multimedia content, and advanced CSS styling.

## What I Built

### 1. Expense Table
The expenses section contains a table with:
- Name
- Amount
- Category
- Date

It includes five sample expenses using HTML table elements such as `table`, `thead`, `tbody`, `tr`, `th`, and `td`.

### 2. Add Expense Form
The Add Expense section contains:
- Expense name input
- Amount input
- Category dropdown
- Add Expense button

The category dropdown contains Food, Transport, Rent, Entertainment, and Other.

### 3. Multimedia
The page includes an image logo and an embedded YouTube video using an iframe.

### 4. Interactive Elements
A details and summary section explains how to use the tracker. Table rows also have hover effects.

### 5. CSS Selectors
The stylesheet uses:
- Descendant selectors
- Direct child selectors
- `:nth-child()` and `:first-child`
- `:not()`
- `:focus`
- `:hover`

## Files

- `index.html` - Contains the structure and content of the Budget Tracker.
- `style.css` - Contains the styling and CSS selectors.
- `README.md` - Explains the project and its features.
